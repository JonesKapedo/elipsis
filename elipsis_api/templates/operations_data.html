JSON API

Session cookie or bearer token
GET /api/v1/operations

Summary, lane health, latest metrics, incident counts, and compliance counts.

GET /api/v1/operations/metrics

Latest metric per organisation, with target, status, and prior-period movement.

POST /api/v1/operations/metrics

Write a reading. Body: metric_key, value, period_end, optional note.

POST /api/v1/operations/incidents

Open an incident. Body: title, optional severity, lane, impact, cause, owner.

GET /api/v1/operations/documents

Compliance register with expiry state and days remaining.

GET /api/v1/operations/export

Full JSON bundle for a warehouse, data lake, or backup.

curl {{ request.base_url }}api/v1/operations \
  -H "Authorization: Bearer $ELIPSIS_TOKEN"

curl -X POST {{ request.base_url }}api/v1/operations/metrics \
  -H "Authorization: Bearer $ELIPSIS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"metric_key":"on_time_delivery","value":94.2,"period_end":"2026-10-31"}'

A token is already scoped to its organisation, so organization_id is not required in token-authenticated writes.
