3. Scoring pipeline

A · Evidence-adjusted answers

Scores are tempered by evidence strength so “we think so” does not equal “we can show it”.

B · Subdomain → pillar roll-up

Weighted means by subdomain, then by pillar, then into the {{ INDEX_SHORT }} (0–100).

C · Declarative metrics

36 formulas evaluated by a restricted AST interpreter. Typos fail at import — no silent wrong numbers.

D · Pain → roadmap

Low scores trigger named pain points; recommendations phased by complexity and modelled ROI.

5. Financial model

Annual savings sized from staff count, blended hourly rate, recoverable friction, and a conservative ceiling on the labour line so board packs stay credible.

  • Hours × rate driven by organisation size (default rate in constants)
  • Severity scales with low subdomain scores
  • Recoverable value capped (default 12% of labour line)
  • Investment, payback months, 3- and 5-year return printed with assumptions
