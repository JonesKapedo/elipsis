8. Financial impact model — deep dive

Friction cost is not a line item on the P&L — it is the annualised cost of manual workarounds, rework, wait states, and under-used capacity that the assessment signals expose. The model converts those signals into {{ CURRENCY }} using stated headcount, a blended labour rate, and a conservative savings ceiling so the number is useful in a board pack without overclaiming.

How to read this section. Treat annual savings as an upper bound for prioritisation, not a budget request. The payback period assumes sequenced delivery of the roadmap’s highest-ROI items; delaying Horizon 1 extends payback roughly in proportion to delayed savings capture.
