SECURITY & TRUST

Designed for serious operational data.

Session-based access, hashed passwords, and explicit share links — so board packs move by design, not by screenshot.

A

Authentication

PBKDF2-HMAC-SHA256 password hashing. HttpOnly session cookies with SameSite=Lax; Secure flag on HTTPS (Vercel).

B

Share links

Completed reports can be shared via unguessable tokens. Recipients do not need an account; links are read-only.

C

Data durability

Configure ELIPSIS_DATABASE_URL to PostgreSQL for production. SQLite on serverless is ephemeral by design.

D

Admin hygiene

Set ELIPSIS_ADMIN_EMAIL and ELIPSIS_ADMIN_PASSWORD before public exposure. Defaults are for demos only.

Operational recommendations

  • Use a managed Postgres (Neon, Supabase, RDS) in production
  • Rotate admin credentials after first deploy
  • Treat share links as sensitive — revoke by clearing demo data or rotating tokens in a future release
  • Review API access under /docs before integrating downstream systems
